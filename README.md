# Employee Workforce Analytics Dashboard

## Project Overview
An interactive Employee Workforce Analytics Dashboard developed using Microsoft Excel to analyze employee data and generate meaningful workforce insights.

## Dashboard Features
- Gender-wise employee distribution
- Employee count by location
- Department-wise employee count
- Active vs. Non-Active employee analysis
- Employee count by age group
- Designation-wise employee analysis

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers and Interactive Filters
- Data Analysis and Visualization
